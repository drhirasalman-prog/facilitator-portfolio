# Professional Facilitator Portfolio

A single-page, fillable portfolio for HPE702 | Facilitating Learning Experiences in Multiple Settings.

Sections:

1. Personal teaching philosophy
2. Facilitation session plans
3. Peer feedback
4. Reflective narratives
5. Critical incident reflections
6. Professional development goals
7. Evidence across cognitive, psychomotor and affective domains

## Using it

- Open the page and type into any field. Entries save automatically in your own browser (localStorage).
- **Download as PDF** creates a formatted file for submission.
- **Copy portfolio as text** copies everything to the clipboard as a backup.
- Entries stay on your device and are never uploaded. Clearing your browser data removes them, so download a PDF regularly.

## Hosting

The site is one static file (`index.html`) with no build step. It loads jsPDF from cdnjs for PDF export.
Enable GitHub Pages from Settings > Pages > Deploy from a branch > `main` / root.
